# UI 国际化（i18n）

> **类型**：技术参考（现行有效）　**最后同步**：2026-09-30
> 代码在 `src/lang/`。注意与 `langs.ts`（学习语言系统：母语/外语/词典/发音）区分，见根 [AGENTS.md](../../AGENTS.md)。

## 机制

- 词条文件：`src/lang/locale/en.ts`（**类型源**）、`zh.ts`、`zh-TW.ts`（`Partial<typeof en>`）
- 取词：`t(text)` 来自 `src/lang/helper.ts`，每次调用动态解析界面语言：`localStorage["language"]` → `navigator.language`（含 BCP-47 基础码回退 zh-CN→zh）→ en
- 缺键回退：`en[text]`，即 **en.ts 缺键 = 渲染 undefined；zh 缺键 = 显示英文原文**

## 新增 UI 文案的流程

1. `en.ts` 加键（值即键名）——这是 `t()` 的 `keyof` 类型源，漏加会在 .ts 报错（.vue 不会，见陷阱）
2. `zh.ts` / `zh-TW.ts` 同步翻译——**zh-TW 最容易漏**
3. 模板/脚本一律 `t("Key")`，禁止硬编码文案（含 placeholder、title、下拉选项 label）

## 陷阱

- **`.vue` 文件不在 tsc 检查范围**（`build:check` 的 plain tsc 只查 .ts）：vue 里 `t("不存在的键")` 不会报错，运行时静默显示英文/undefined。2026-09-30 审计修复过一批（Loading.../No more data/And/Or/Word Details/Meaning is empty! 等）
- 大量误报匹配来自 `split("...")`/`format("...")` 等以 `t(` 结尾的调用，审计词条时注意排除
- 语言解析在 helper.ts，2026-09-30 起支持系统区域回退；改动它要同时验证 Obsidian 语言设置三种情况（zh / zh-TW / en）

## 词条分区约定

locale 文件按引入组件用注释分区（如 `// LearnPanel.vue`、`// settings`），新增词条放进对应分区，便于对照来源。
