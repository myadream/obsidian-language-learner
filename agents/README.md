# agents/ — 项目文档目录

本目录存放面向编码代理与协作者的项目文档。入口文档是仓库根目录的 [agent.md](../agent.md)（项目概况、命令、架构总览、陷阱清单），本目录只放专题文档。

## 文档架构

文档按**生命周期**分两类，新增文档前先判断归属：

| 类型 | 特征 | 放置规则 |
|------|------|----------|
| **历史方案**（plan） | 描述一次性的改造任务，完结后归档。允许保留当时的表述，但**过时的架构描述必须就地修正或加"历史说明"注记**，避免误导后续读者 | `agents/<模块> plan.md` |
| **技术参考**（reference） | 描述**现行**的机制/约定，随代码演进同步更新，内容必须始终与代码一致 | `agents/<主题>.md` |

> 不在此目录存放：会话级临时产物（.tmp 文件用完即删）、可在代码里直接读到的结构说明（避免与代码重复漂移）。

## 维护约定

1. **代码改了，参考类文档同步改**：改动存储契约、语言系统、颜色系统等被参考文档描述的机制时，同一次提交内更新对应文档。
2. **方案文档完结后不删**：作为决策背景归档，但要在文首标注状态与最后同步日期。
3. **架构性结论优先写进根目录 agent.md**：跨模块的约定（命令、验证流程、语言代码、存储契约参数序等）以 agent.md 为单一入口，本目录文档只展开专题细节，必要时互相链接。
